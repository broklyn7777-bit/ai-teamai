# 安全红线禁忌

## 权限与鉴权

- ⛔ 禁止业务接口遗漏 `@PreAuthorize` 注解，禁止权限标识定义混乱、重复，禁止匿名访问业务接口
- ⛔ 禁止在代码中硬编码权限检查（如 `if (permission.contains("xxx"))`），必须使用 `@PreAuthorize` 注解
- ⛔ 禁止直接调用 `SecurityUtils.hasPermission()` 进行权限检查，这是过时方式
- ⛔ 禁止跳过数据归属校验，增删改操作必须额外校验数据是否属于当前用户/租户，防止越权操作
- ⛔ 禁止在 Service/Dao 层绕过权限检查直接查询数据
- ⛔ 禁止获取用户信息后不验证，`getLoginAuthDto()` / `getLoginAuthInfo()` 返回值必须做 null 校验

## 数据加密

- ⛔ 禁止非敏感字段添加 `@EncryptField`/`@DecryptField`，禁止主键/索引字段加密
- ⛔ 禁止手动加解密与自动加解密混用，禁止遗漏 `@EncryptionClass` 标记
- ⛔ 禁止遗漏 `@Decrypt`/`@Encrypt` 注解
- ⛔ 禁止自定义加密工具、自定义加密算法、使用不安全加密算法（DES、MD5）
- ⛔ 禁止引入第三方不安全加密包

## 密钥与配置安全

- ⛔ 禁止 Jasypt 密码硬编码于配置文件，禁止加密密文提交 git 仓库（`ENC(...)` 可提交，密码不可以）
- ⛔ 禁止生产环境通过环境变量明文传递 Jasypt 密码
- ⛔ 禁止密钥硬编码于代码中，禁止明文密钥提交至 git 仓库

## 敏感数据脱敏

- ⛔ 禁止日志中打印完整敏感数据，禁止接口返回完整敏感字段，禁止数据导出时输出明文敏感数据
- ⛔ 禁止接口返回 VO/DTO 中遗漏脱敏注解，敏感字段必须标注
- ⛔ 禁止在日志中直接打印敏感对象或字段，必须手动脱敏或使用脱敏工具
- ⛔ 禁止混用不同脱敏方式：接口返回值用注解脱敏、日志输出用手动脱敏或工具脱敏

## 通用安全

- ⛔ 禁止捕获大异常不处理
- ⛔ 禁止外部传入代码执行
- ⛔ 禁止未校验文件上传
- ⛔ 禁止直接使用用户输入拼接 SQL（必须参数化查询）
- ⛔ 禁止重写 Cookie/Session 不安全方法
- ⛔ 禁止敏感接口遗漏鉴权注解
- ⛔ 禁止跨租户查询数据，必须在查询条件中加入 `tenantId` 或通过 `SecurityUtils.getTenantId()` 隔离数据
