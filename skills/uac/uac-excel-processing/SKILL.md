# Skill: Excel-Development
# 适用场景：聚焦Excel导入导出的性能、安全、异常处理，规避OOM、数据错乱问题

## 一、强制基础规范

1. **框架选型**：统一使用阿里 **EasyExcel**，禁止 POI 原生 SXSSF/XSSF
2. **实体命名**：映射实体命名为 `XxxExcelDTO`/`XxxExcelVO`，单独存放于 `excel` 包下
3. **字段注解**：使用 `@ExcelProperty` 指定列名+列索引，必填字段加 `@ExcelIgnoreUnannotated`
4. **数据量限制**：单次导出≤1万行，单次导入≤5000行

## 二、导入核心规范

1. **文件校验**：仅支持 `.xlsx`，≤20MB，校验文件头魔数
2. **数据校验**：必填字段、手机号、身份证等在监听类中做双重校验，失败标注行号+错误原因
3. **流式读取**：分页监听模式，每 500-1000 行批量入库，禁止一次性加载全部
4. **权限校验**：导入接口必须校验登录态与业务权限
5. **错误反馈**：失败生成错误明细 Excel，标注错误行/字段/原因
6. **重复校验**：通过业务唯一标识校验重复，重复数据标记跳过

## 三、导出核心规范

1. **流式导出**：直接写入 Response 输出流，禁止加载全部到内存
2. **响应头**：文件名编码 UTF-8，格式：`业务模块_日期_random.xlsx`
3. **字段脱敏**：敏感字段（手机号/身份证/银行卡）强制脱敏
4. **查询优化**：分页查询，禁止全表查询
5. **超时处理**：大数据量建议异步处理，生成文件后通知下载

## 四、编码禁忌

1. 禁止内存加载模式，必须搭配监听器流式读写
2. 禁止导入导出接口不做权限校验
3. 禁止 IO 流手动关闭，必须 try-with-resources
4. 禁止导入直接抛校验异常，需收集全部错误统一返回
5. 禁止导出敏感数据不脱敏

## 五、核心使用约束

- **统一依赖**：复用框架 `orion-spring-boot-starter-easyexcel`
- **注解驱动**：导入用 `@RequestExcel`，导出用 `@ResponseExcel`，禁止手动解析
- **数据校验**：配合 JSR380 注解做参数校验，异常统一拦截
