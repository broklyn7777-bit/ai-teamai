# Java 文件存储规范

> 详细的代码模板、配置示例请参见 Skill `uac-file-storage`。

## 🔴 核心禁忌

| 禁忌 | 正确做法 |
|---|---|
| 直接使用用户传入的文件名存储 | UUID 重命名，原始文件名仅展示 |
| 文件存储到应用服务器本地 | 统一使用 OSS 分布式存储 |
| 仅校验文件后缀 | 前端后缀 + 后端魔数双重校验 |
| 上传接口无权限校验 | 必须校验登录态 |
| IO 流不使用 try-with-resources | 自动关闭流 |
| 返回文件物理路径/密钥给前端 | 禁止暴露存储细节 |
| 异常直接抛出不捕获 | 捕获返回标准化提示 |

## 必守原则

1. **框架**：`orion-spring-boot-starter-filestore`，禁止手写工具类
2. **存储类型**：优先 soss 对象存储，禁止混用
3. **文件命名**：UUID + 原始后缀，禁止中文/特殊字符/`../`
4. **路径规范**：`业务域/模块/日期/随机文件名`
5. **大小限制**：单文件 ≤ 50MB，图片 ≤ 10MB，大文件分片上传
6. **防盗链**：私有文件生成时效签名链接，≤ 30 分钟
7. **表结构**：使用框架 `sys_file` 表，禁止修改字段
